# PixelForge Studio

A lightweight browser-based photo editing app inspired by Picsart-style editing flows.

## Features
- Upload images and edit on a canvas preview.
- Tone adjustments: brightness, contrast, saturation, blur, hue, opacity.
- One-click style filters (B&W, vintage, invert, pop).
- Rotate and flip transforms.
- Add caption text overlays.
- Export final image as PNG.

## Run locally
Open `index.html` directly or serve the directory:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
